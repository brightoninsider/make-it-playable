# Signal Sprint starter

Serve this folder locally:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). No package installation, account, network service, or CDN is used. Edit the `CONFIG` object at the top of `app.js` to change the title, subtitle, colours, seed, or replace the loop entirely.

Run the core tests with Node 20+:

```bash
node --test *.test.mjs
```

This is a deliberately small collect-and-avoid tracer. Its geometry is intentional final-quality starter art, not a claim that every resulting game should use geometric art.
